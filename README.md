# landing-page
# Coffee House

A clean, responsive landing page for a neighborhood coffee shop, built with plain **HTML** and **CSS**.

> **Note:** This project is currently a work in progress. JavaScript functionality (cart, ordering, interactivity) will be added soon.

---

## About

**Coffee House** is a landing page designed to showcase a coffee shop's brand, menu, and ordering call-to-action. It features a bold hero section, a specialty menu grid, a motivational quote, and a prominent order button, all styled with a modern, dark-and-light color palette.

This project was built as a learning exercise to practice **semantic HTML**, **CSS Flexbox**, **CSS Grid**, and responsive layout principles.

---

## Features

- **Hero section** with a bold headline, subheading, and "Place order" CTA
- **Navigation bar** with links to Home, About, Menu, Cart, and Contact
- **Menu grid** displaying four house specialties (Americano, Latte, Hot Chocolate, Chai Latte) with images, descriptions, and photographer credits
- **Quote section** for brand personality
- **Call-to-action banner** encouraging users to place an order
- **Footer** with copyright information
- **Responsive layout** using Flexbox and CSS Grid

---

## Built With

- **HTML5**: semantic structure (`header`, `nav`, `figure`, `figcaption`, `footer`)
- **CSS3**: Flexbox, Grid, custom color palette, typography
- **Google Fonts**: Roboto (referenced in CSS)
